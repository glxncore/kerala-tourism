# THΛNAL (തണൽ)
> **Premium Kerala Travel Discovery Platform**

[![Kerala Tourism](https://img.shields.io/badge/Kerala-God's%20Own%20Country-173B32?style=flat-square)](https://github.com/glxncore/kerala-tourism)
[![License: MIT](https://img.shields.io/badge/License-MIT-C9A875?style=flat-square)](LICENSE)

*ThΛnal (തണൽ)* is an editorial Kerala travel discovery platform designed with luxury editorial typography, organic nature tones, and an interactive travel guide architecture.

---

## ✨ Features

- **Interactive Vector Map**: 100% accurate vector boundaries generated from official Kerala GeoJSON data (`data/district.geojson`). Features district hover highlights, tooltips, and click-through navigation.
- **14 Dedicated District Guides**: Comprehensive editorial guides for all 14 districts from Kasaragod to Thiruvananthapuram, detailing ideal seasons, elevation, character, key experiences, and local cuisine.
- **Fast Live Search**: Real-time debounced search across districts, destinations, foods, and experiences with instant highlight and category tagging.
- **Explore by Mood**: 12 curated emotional palettes (Escape, Mountains, Coast, Backwaters, Monsoon, Wildlife, Food, Culture, Photography, Adventure, Slow Travel).
- **Hidden Kerala**: Signature editorial section showcasing lesser-known gems (Aymanam, Maravanthuruthu, Kadamakudy, Muzhappilangad, Ponnumthuruthu).
- **Taste Kerala**: Culinary heritage guide highlighting Sadya, Karimeen Pollichathu, Appam & Ishtu, Malabar Parotta, Puttu, and more.
- **Build Your Kerala (Trip Planner)**: Curated itinerary generator tailored to duration, interests, travel style, and arrival gateway.
- **My Kerala (Saved Destinations)**: Client-side wishlist powered by `localStorage` with off-canvas drawer management.
- **Stories from Kerala**: Travel magazine essays focusing on slow travel and intimate coastal rhythms.
- **Responsible Travel**: Highlighting community homestays and the Kerala Responsible Tourism Mission.

## 🚀 Getting Started

ThΛnal is built with standard web technologies (HTML5, CSS3, ES6+ JavaScript) and has zero external npm build dependencies.

1. Clone or download the repository:
   ```bash
   git clone https://github.com/glxncore/kerala-tourism.git
   ```
2. Open `index.html` in any modern web browser or serve with a local server:
   ```bash
   # Using Python
   python -m http.server 8000

   # Or using Node.js
   npx serve .
   ```
